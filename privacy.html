Privacy Policy

Auto Draft · last updated November 9, 2026

Who runs Auto Draft

Auto Draft is a private tool run by Segan Music. It sends Segan Music's own clips to Segan Music's own TikTok account as drafts. It is not offered to the public, and only TikTok accounts that Segan Music has added can connect to it.

What Auto Draft receives from TikTok

When an account holder signs in with TikTok and approves the request, Auto Draft receives:

  • Basic profile information: the account's open id, display name and avatar.
  • An access token and a refresh token that let it upload content to that account as drafts.
  • The status of each upload it made, such as whether a draft reached the inbox.

Auto Draft does not read the account's videos, followers, messages, likes or any other activity.

How that information is used

The tokens are used for one thing: uploading the clips the account holder chose to that account's TikTok drafts. The profile information is used only to confirm that the right account is connected.

Where it is kept

The tokens and the open id are stored on a computer owned by Segan Music, in the operating system's encrypted keychain. They are not kept on any server, and they are sent only to TikTok.

Sharing

Auto Draft does not sell, rent or share any information with anyone. It uses no advertising and no analytics.

This website

This website sets no cookies and runs no trackers. It is hosted on GitHub Pages, and GitHub may log visitors' IP addresses as described in GitHub's own privacy statement.

Removing access and deleting data

An account holder can disconnect Auto Draft at any time in the TikTok app under Settings and privacy, Security and permissions, Manage app permissions. Once access is removed the stored tokens stop working, and they are deleted from the computer. To ask for deletion directly, message @seganmusic on TikTok.

Children

Auto Draft is not directed at children and is not available to them.

Changes

If this policy changes, the new version is published on this page with a new date.
